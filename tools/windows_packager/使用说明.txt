Z5 Extensions 使用说明

适用机型：尼康 Z 5，固件 C 1.50。
本项目与尼康公司无关。刷入修改过的固件可能损坏相机，请先阅读完整说明并自行决定是否操作。

当前是竖拍测试版：竖拍显示、竖拍触控仍在测试。竖拍下 i 菜单的二级页、三级页和触控，只按作者相机上自定义的
12 个 i 菜单项目测试过（设定优化校准、ISO 感光度、闪光模式、静音拍摄、HDR、AF 区域模式、白平衡、
动态 D-Lighting、测光、选择影像区域、减震、对焦模式），换成其他项目不确定能不能正常用。已知问题：待机唤醒后电池和焦距要半按一次才出来。

一、生成结果包含什么

EG165050.BIN                 相机固件更新文件（请勿分发）
card\Z5APP.BIN               功能模块
card\SHUTTER\MENU.DAT        设置文件，请保留
card\SHUTTER\1.WAV 至 5.WAV  随附的 5 个测试快门声音
card\Z5LOG\DIAG01～20.BIN     20 个空的测试记录文件，请保留

二、更新固件（只需更新一次，由您自己在相机上操作）

1. 确保相机电量充足；将 EG165050.BIN 放到存储卡根目录，卡根目录只放这个更新文件。
2. 在相机进入“设定菜单 → 固件版本 → 更新”，按照屏幕提示完成更新。
3. 关闭相机，取下电池片刻后重新装回。
4. 从存储卡上删除 EG165050.BIN。

三、安装卡上功能文件

把生成结果中 card 文件夹内的内容复制到存储卡根目录，最终结构如下（盘符 A: 仅为示例）：

A:\Z5APP.BIN
A:\SHUTTER\MENU.DAT
A:\SHUTTER\1.WAV
A:\SHUTTER\2.WAV
A:\SHUTTER\3.WAV
A:\SHUTTER\4.WAV
A:\SHUTTER\5.WAV
A:\Z5LOG\DIAG01.BIN 至 DIAG20.BIN

MENU.DAT 和 Z5LOG 里的 20 个文件必须事先放在卡上并保留。相机自己新建的文件无法可靠保存。

四、更换自定义快门声音

1. 准备 WAV 声音文件，文件名必须为 1.WAV、2.WAV、3.WAV、4.WAV 或 5.WAV。
2. 将文件放入存储卡根目录的 SHUTTER 文件夹，同名文件会替换该编号的声音。最多支持 5 个，不必全部放齐。
3. 文件格式须为标准 44 字节 WAV 文件头、未压缩 PCM、48 kHz、16 位、立体声；文件至少 2000 字节，最多读取约 1.28 秒。建议声音从文件开头立即响起，避免开头静音造成延迟。
4. 相机开启静音拍摄后，在设定菜单 → 扩展功能 → 快门声音中选择声音类型（对应文件编号）、开关和音量；替换声音后可使用“重新载入”。

声音格式不符合要求时，可双击本文件夹里的“快门声音转换工具.exe”：选择 WAV 原文件、选择声音编号 1～5，选择电脑上的保存位置并转换。转换结果已经按编号命名，将其复制到卡上的 SHUTTER 文件夹。转换工具不接受 MP3 等非 WAV 输入，不覆盖已有文件；如需替换，请由您自行复制并确认覆盖。转换结果尚需实机试听（camera_verified: false）。

五、扩展功能菜单

设定菜单最后一行“扩展功能”，进去是：
  快门声音        开关、类型、音量、重新载入
  照片高光显示    还需在自定义设定 g 组打开原厂“高光显示”图案
  竖拍显示        竖着拿相机时界面转为竖版（默认打开）
  竖拍触控        竖拍时的触摸；关闭后竖拍下触摸不起作用，横拿不受影响
  焦距显示        所有 CPU 镜头显示焦距
  电量显示        电池图标里显示剩余电量百分比，20% 以下变红
  保存测试记录    出问题时按 OK 保存一份记录（见第七节）
取景网格：在自定义设定 d8 中选择开启（4×4）、关闭、3×3 或 2×2。
直方图与水平仪同框：按 DISP 切到水平仪页；“将设置应用于即时取景”需开启，开机或唤醒后约 1 秒出现。
模块状态：在“我的菜单”最后一行查看，“正常 …”表示模块工作正常。

六、恢复

如出现死机，电源开关和拔卡可能没有反应：先取下电池，再拔卡或在电脑上删除卡内 Z5APP.BIN，然后重新装电池开机。彻底恢复时，请从尼康官网下载 Z 5 C 1.50 固件并按官方步骤重新更新。

七、反馈测试问题

1. 让问题出现，停在出问题的画面，用手机拍一张屏幕照片。
2. 马上进入 设定菜单 → 扩展功能 → 保存测试记录，按 OK。这一行会显示“已存 01”这样的编号，记下编号，
   并写一句当时做了什么、看到了什么（例如：竖拿、手柄朝上，在 i 菜单里打开优化校准，向左拖动没有反应）。
3. 显示“已满”说明 20 个文件都用完了：先把记录发回，再用新的空文件覆盖卡上的 Z5LOG，又从 01 开始。
   存满后不会自动覆盖，旧记录不会丢。
4. 发回：卡上 Z5LOG 里写过的 DIAG 文件、对应的照片和说明。记录里只有界面绘制、触摸和电池等状态，
   没有照片内容，也没有个人信息。不要格式化存储卡，否则这些文件会一起被删掉。
