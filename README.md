# Z5 Extensions

[English](README.en.md)

尼康 Z 5（固件 C 1.50）的功能扩展。**本仓库不含任何尼康固件**：你需要自备官方更新文件，由 `patch.py` 在本机校验并生成刷机文件。

与尼康公司无关，也未获其授权或支持。**刷入修改过的固件有使相机损坏的风险，一切后果自负。** 目前只在作者的一台相机上测试过。

## 功能

| 功能 | 说明 | 实机验证 |
| --- | --- | --- |
| 自定义快门声音 | 播放卡上的 WAV，最多 5 个音效，可调类型、音量；电子快门、机械快门分开开关（机械默认关） | **作者实机测试通过**（A55） |
| 中英文菜单 | 卡上模块的所有菜单都有中英两种文字，自动跟随相机语言：简体、繁体中文显示简体中文，其他语言显示英文。见下文“英文适配” | 中文：作者实机使用；英文：模拟器核对（照片画幅页除外），实机未单独记录 |
| 直方图水平仪同框 | 水平仪页同时显示直方图 | 通过（照片模式、背屏） |
| 取景网格样式 | 自定义设定 d8 增加 3×3 和 2×2，原厂“开启”仍是 4×4 | 通过（照片模式、背屏） |
| 照片高光显示（斑马纹） | 把原厂视频的高光显示用到照片取景，设定菜单单独开关 | 通过（照片模式、背屏） |
| 待机唤醒修复 | 熄屏后立刻唤醒时功能不丢失 | 通过 |
| 竖拍显示（测试版） | 竖着拿相机时取景信息、i 菜单、设置页转为竖版 | 作者实测，仍在测试 |
| 竖拍触控（测试版） | 竖拍时触摸按竖版位置操作，含拖动选项条；可关闭 | 作者实测“差不多可以用” |
| 焦距显示 | 所有 CPU 镜头都显示焦距（原厂只限电动变焦），可关闭 | 通过 |
| 电量百分比 | 电池图标里显示剩余电量百分比，可关闭 | 通过 |
| 扩展功能菜单 | 所有开关集中在设定菜单最后一行“扩展功能” | 通过 |
| 自定义 DISP | DISP0～DISP3 可分别设置水平线、直方图和详细信息，后屏和取景器分别记忆页号 | 用户反馈 A39 测试正常；A52 作者实机测试通过 |
| B 门定时 | 在照片拍摄菜单设时、分、秒、张数和间隔，按「开始」退出菜单，约 1.5 秒后曝光 | **作者实机测试通过**（多张和间隔为 A55） |
| 照片画幅 | 照片拍摄菜单选 4:3 或 2.33:1，JPG 和 NEF 按该比例记录，背屏和取景器有遮幅（需打开自定义 DISP）。只拍 NEF 时机内回放、放大也按所选比例显示（A91）。**已知问题**：拍后遮罩在原厂图标处出现空框、只拍 NEF 时即时回放第一次放大偶尔黑屏或花屏、2.33:1 放大时导航小窗有形变，见[说明](docs/PHOTO_ASPECT.md) | **作者实机测试通过**（A91） |
| 胶片颗粒 FILM | FUJI400 / HP5、强度 1–6，加在 JPG 和 NEF 内嵌预览上；每张约 1.1 秒。**开着颗粒时不建议高速连拍**（低速每秒 3 张连拍 20 多张不卡；高速连拍 4 张后等 1–2 秒）。实现方法与参数见[说明](docs/FILM_GRAIN.md) | **作者实机测试通过**（A52） |
| NEF 内写入 Lightroom 颗粒 | “NEF写入：开”时相机把颗粒设置写进 NEF 自带的 XMP；Lightroom 原始默认设置选“相机设置”，导入即自动带颗粒，不产生额外文件 | **作者实机测试通过**（Lightroom Classic 13.2） |
| 电脑读取照片加速 | USB 连电脑浏览照片时加快列表读取（移植 Z30 mtp-fast），卡上有模块时自动生效 | 作者已上机，**加速效果未验证** |
| 测试记录 | 出问题时一键保存记录（`Z5LOG` 文件夹），便于反馈 | 通过 |
| 连拍提速（测试版） | 机械 233→约 195 ms/张（全画幅和 DX 镜头都已实测）；**静音目前没有明显提速**（约 380 ms/张，原厂 400，排查中）；**只适合 AF-S，AF-C 下也按 AF-S 工作，不适合追踪**；A50 起每次开机默认关；详见[说明](docs/BURST_SPEED.md) | 上游旧产物机械通过、静音未生效；本次组合待实机验证 |

取景器、视频模式下的新功能，以及最新版本的拔卡恢复，尚未单独确认。已完成和未来计划见 [PLAN.md](PLAN.md)，开发过程见 [docs/PROGRESS.md](docs/PROGRESS.md)。

**当前版本 A91**：照片画幅的 NEF 改用原厂 RAW 尺寸（Lightroom 能直接打开，按所选比例裁切显示），只拍 NEF 时机内即时回放、回放和放大按所选比例正常显示；安装器不需要 Python，并提供英文版。A81 起已有照片画幅 4:3 / 2.33:1、B 门多张和间隔、电子/机械快门声音分开开关、菜单跟随相机语言（英文或简体中文）。作者已实机测试通过（电脑读取照片加速的效果仍未验证）。

**照片画幅的已知问题**（不影响照片的实际画幅）：拍完照回到取景时，遮罩在原厂图标处出现空框；只拍 NEF 时，即时回放第一次按放大偶尔黑屏或花屏，再按一次即正常；2.33:1 放大时右下角导航小窗有些形变；回放放大只对当前所选比例的照片有效。全部已知问题见[照片画幅说明](docs/PHOTO_ASPECT.md)。开着胶片颗粒时请尽量不要高速连拍，见[胶片颗粒说明](docs/FILM_GRAIN.md)。

A39 合并 A19 的 B 门定时和 PR #6 的自定义 DISP。自定义 DISP 开启后，可逐页设置水平线（关闭／原版／TypeA）、直方图和详细信息。关掉详细信息时隐藏白平衡图标，保留基础参数和电量。后屏保留 DISP4 熄屏档，取景器循环四个显示页。

竖拍仍为测试功能。待机唤醒后电池和焦距可能需要再半按快门才出现。竖拍 i 菜单和触控的覆盖范围见[竖拍显示说明](docs/PORTRAIT_UI.md)。绘制和持久化细节见[自定义 DISP 交接文档](docs/CUSTOM_DISP_HANDOFF.md)。用户已反馈 A39 测试正常，视频和各显示场景未逐项记录。

功能代码放在存储卡上的模块里。固件只增加很小的入口和判断；卡上没有模块时，网格、高光显示和同框都走原厂路径。改动只在 MAIN 模块内，不动引导区。

## 英文适配

卡上模块的菜单有中英两种文字，不需要设置，跟随相机的语言：相机为简体或繁体中文时显示简体中文，其他语言一律显示英文。

| 菜单 | 英文显示 |
| --- | --- |
| 扩展功能 | Extensions（Shutter sound、Photo zebra、Portrait UI、Focal length、Custom DISP、FILM 等） |
| 照片画幅 | Photo aspect: Off / 4:3 / 2.33:1 |
| B 门定时 | Timed Bulb（Start、Hours、Minutes、Seconds、Shots、Interval） |
| 胶片颗粒 | FILM（Off / FUJI400 / HP5、Strength、NEF write） |
| 连拍提速、保存测试记录 | 同样有英文 |

Windows 工具 `Z5Extensions.exe` 和它附带的使用说明目前只有中文；英文说明见 [README.en.md](README.en.md)。

## Windows 免安装工具

从 [A91 发布页](https://github.com/WonderLantern/wonder-lantern-z5/releases/tag/a91-20261126) 下载 `Z5Extensions.exe`（中文界面）或 `Z5Extensions-EN.exe`（英文界面），选择自备的原厂 `Z_5_0150.bin`，即可在电脑上生成 A91 固件和卡上文件。程序是独立的 Windows 程序，电脑上不需要安装 Python。发布页只提供这两个程序，不再提供单独的模块或版本更新包；更新时下载新的 exe 重新生成即可。结果中包含说明和快门声音转换工具（中文版为中文，英文版为英文）。首次生成需联网下载并校验解码器；下载失败（例如开了 GitHub 加速器、代理或杀毒软件的 HTTPS 扫描）时，程序会给出链接，用浏览器下载解码器压缩包后在程序里选择它即可，每个文件仍按固定的 SHA-256 核对。

## 使用

**A91 需要新的固件**（只拍 NEF 回放的入口）。从任何旧版本升级（包括 SHA-256 以 `13525d9b` 开头的 A81 固件）都要按下面步骤刷一次，并同时替换卡根目录的 `Z5APP.BIN`。升级前备份卡上的 `Z5APP.BIN` 和 `SHUTTER/MENU.DAT`；保留原来的 `MENU.DAT` 可以沿用设置。

### 1. 准备

- Python 3.10 或更新版本。
- 尼康官网下载的 Z 5 C 1.50 更新文件 `Z_5_0150.bin`，SHA-256 为
  `efc0ce70dcafdd96c64e95d8d50f6b7f0509fc0c2840b28d12b6f9e4877ee776`。

### 2. 生成文件

下载本仓库后，在仓库目录运行：

```bash
python patch.py --source Z_5_0150.bin --output output
```

工具首次运行时会从 [z5mod](https://github.com/youyli03/z5mod) 下载固定版本的解码文件并校验哈希，需要联网。生成结果必须与发布清单逐字节一致，否则不会写出文件。输出：

```text
output/EG165050.BIN              刷机文件
output/card/Z5APP.BIN            卡上模块
output/card/SHUTTER/MENU.DAT     设置文件，必须保留
output/card/SHUTTER/1～5.WAV      默认测试音效（5 个）
output/card/Z5LOG/DIAG01～20.BIN  20 个空的测试记录文件
```

`EG165050.BIN` 的 SHA-256 应为 `1f838b83f624397182813ee68c4e9fb0b697b40c5a48843f5bb6081a5dcb5cca`（A52 固件 + 照片画幅的入口）；`card/Z5APP.BIN` 应为 `1176e275fa2b3b928208ad51368e29f731e137bbfb40f8cdfeda2ac9da4e28cb`。请勿分发这个文件。

### 3. 刷机（只做一次）

1. 电量充足，卡根目录只放 `EG165050.BIN`。
2. 设定菜单 → 固件版本 → 更新，按屏幕提示完成。
3. 关机，取下电池片刻再装回。
4. 删除卡上的 `EG165050.BIN`。

### 4. 存储卡

把 `output/card/` 里的内容复制到卡根目录，自带 5 个测试音效，也可以换成你自己的：

```text
A:\Z5APP.BIN
A:\SHUTTER\MENU.DAT
A:\SHUTTER\1.WAV ~ 5.WAV
A:\Z5LOG\DIAG01.BIN ~ DIAG20.BIN
```

相机自己新建的文件留不住，所以 `MENU.DAT` 和 `Z5LOG` 里的 20 个记录文件必须事先放在卡上。

### 5. 音效格式

仓库自带 5 个测试音效。自定义时文件名必须是 `1.WAV` 到 `5.WAV`，不需要 5 个都有。标准 44 字节文件头的 WAV，未压缩 PCM，48 kHz，16 位，立体声，至少 2000 字节，最多读取约 1.28 秒。声音要从文件开头就响，开头的静音会让快门声听起来变晚。

转换工具（需要 Python 3）：

```bash
python tools/make_snd_wav.py 你的声音.wav --out 转换结果
```

结果是转换目录里的 `SND.WAV`，改名后放进 `SHUTTER`。

### 6. 菜单

设定菜单最后一行“扩展功能”，进去是：

| 项目 | 说明 |
| --- | --- |
| 快门声音 | 电子快门、机械快门分开开关，可调类型、音量，“重新载入”重新读取声音文件 |
| 照片高光显示 | 还需要在自定义设定 g 组把原厂“高光显示”的图案打开 |
| 竖拍显示 | 竖拍界面总开关（生成的设置文件默认打开） |
| 竖拍触控 | 竖拍时的触摸；关闭后竖拍下触摸不起作用，横拿不受影响 |
| 焦距显示 | 所有 CPU 镜头显示焦距 |
| 电量显示 | 电池图标里显示百分比，20% 以下变红 |
| 自定义 DISP | 总开关控制四页接管；进入 DISP0～DISP3 分别设置水平仪、直方图、详细信息；LCD/EVF 分别记忆页号 |
| FILM | 胶片颗粒：关闭 / FUJI400 / HP5、强度 1–6、NEF写入（开：把 Lightroom 颗粒写进 NEF）。见[胶片颗粒说明](docs/FILM_GRAIN.md) |

**保存测试记录**在设定菜单最后一行：出问题时停在那个画面，按 OK 保存，行上显示“已存 01”这样的编号；20 个存满后循环覆盖最旧记录。


设定菜单“扩展功能”下面还有一行 **连拍提速**，进去是“机械快门提速”“电子快门提速”两个开关（每次开机默认关，打开后只在本次开机有效）。开着提速时原厂“连拍时查看全部”不能在连拍中显示取景；曝光和对焦停在第一张，只适合 AF-S。详见 [docs/BURST_SPEED.md](docs/BURST_SPEED.md)。

其他：

- **取景网格：** 自定义设定 d8，选开启（4×4）、关闭、3×3 或 2×2（中心十字）。
- **同框：** 按 DISP 切到水平仪页。开机或唤醒后约 1 秒出现，需要“将设置应用于即时取景”为开启。
- **自定义页：** 总开关打开后，按 DISP 切换逻辑页，原厂实际使用 DISP0；详细信息关闭时使用简单页显示许可，保留基础信息与电池。切页后将两端逻辑页号保存到 `MENU.DAT`，开机有效读取后恢复；失败沿用设置重试与写入校验。直方图使用独立取数与 CPU 批量绘制，减少逐柱原厂图形调用，尚无同条件实机加速倍数。
- **原版试验：** 选择原版后在对应自定义页测试，不再要求先访问原厂水平仪页。L37 恢复原版取姿态与配置，并针对 L30 切 EVF 硬卡调整恢复顺序；是否修复仍需实机确认。
- **状态：** “我的菜单”最后一行显示模块状态与 `L39` 性能读数；计数率不是屏幕实际 fps。

### 7. 反馈测试问题

1. 让问题出现，停在出问题的画面，拍一张屏幕照片。
2. 马上保存测试记录（见上表），记下编号，写一句当时做了什么、看到了什么。
3. 把卡上 `Z5LOG` 里写过的 DIAG 文件、照片和说明一起发给维护者。记录只含界面绘制、触摸和电池等状态，没有照片内容。

## 恢复

死机时电源开关和拔卡可能都没有反应：

1. 取下电池。
2. 拔卡，或在电脑上删除卡上的 `Z5APP.BIN`。
3. 重新装电池开机。没有模块时相机按原厂流程运行。

要彻底恢复，到尼康官网下载 Z 5 C 1.50 固件，按官方步骤重新刷入。
