# 规划

更新于 2026-11-09。候选功能都还没有在 Z 5 上调查，难度只是初步判断。

## 已完成

快门声音、简体中文菜单、直方图水平仪同框、待机唤醒修复、3×3 和 2×2 网格、照片高光显示。

## 下一步

- 补测取景器、视频模式和拔卡恢复。
- 缩短诊断行，或改成只在异常时显示。

## 暂缓

- 比例取景遮幅：半透明压暗，保留原厂网格。
- 比例真实裁切：JPEG、预览、回放按比例输出。

## 依赖模拟器或风险较高

| 功能 | 判断 |
| --- | --- |
| AI 登记人脸对焦 | 理论可行，难度很高，需要原生取景和对焦的模拟 |
| 8-bit Log | 能否实现未知，必须实机验证 |
| 无裁切 4K | 不做：读出速度不够，且可能要改 MAIN 以外的模块 |
| 全宽 2K 录制 | 不做：同样受传感器读出限制 |
