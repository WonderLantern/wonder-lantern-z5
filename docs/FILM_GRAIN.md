# 胶片颗粒（FILM）与电脑读取照片加速

测试版 A51（2026-11-23）。固件 `EG165050.BIN` SHA-256 `a3704c6f7f7891b5d691985b6148af43d7bf4d58a35d862659661b1bd9a6c754`，卡上模块 `Z5APP.BIN` `a817bc598e2960107a4b5d24e40ed782b5f28ed151cd4d3c2da17949bf29fb3e`。两者都由本仓库的 `patch.py` 从用户自备的 `Z_5_0150.bin` 生成，已核对与作者上机的文件逐字节一致。

这一版基于 A39 之前的源码，自定义 DISP 仍是 L21 版，不含 A39 合入的 PR #6 新版自定义 DISP 和原生水平仪。

## 怎么用

设定菜单 → 扩展功能 → FILM：

| 项目 | 说明 |
| --- | --- |
| 关闭 / FUJI400 / HP5 | 颗粒风格。FUJI400 参考富士 400 彩负扫描的颗粒，HP5 偏黑白，可配合相机「单色」优化校准 |
| 强度：1–6 | 颗粒强弱，第 3 档为基准 |
| NEF写入：开 / 关 | 开：相机把对应的 Lightroom 颗粒设置写进 NEF 自带的 XMP，不产生额外文件 |

- 颗粒加在 JPG 上，RAW＋JPEG 和只拍 RAW 时也加在 NEF 内嵌的全尺寸预览上。NEF 的传感器原始数据不改。
- **Lightroom Classic**：在「首选项 → 预设 → 原始图像默认设置 → 全局」选「相机设置」，导入「NEF写入：开」的照片后，「修改照片 → 效果 → 颗粒」自动带数值，可以再调或设为 0。FUJI400 第 1–6 档为数量 16/24/32/40/48/56、大小 40、粗糙度 65；HP5 为 19/28/37/47/56/65、大小 33、粗糙度 65（HP5 的数值按比例推算，未单独校准）。选「相机设置」后，Lightroom 同时采用尼康写入的其他默认值（降噪、锐化等），这与尼康 Zf 的做法相同。
- 颗粒强弱随亮度变化（中间调最明显）；Lightroom 的颗粒各亮度均匀，只能近似。

## 速度与连拍（作者实测）

- 每张主图加颗粒约 1.1 秒（6016×4016），这段时间相机在后台处理，取景和拍摄不受影响。
- 低速连拍设为每秒 3 张：连拍 20 多张不卡顿。
- 高速连拍开到最快：连拍 4 张后开始等待，约 1–2 秒后恢复。
- **建议：开着胶片颗粒时不要高速连拍。** 需要高速连拍时把 FILM 设为关闭，速度与原厂相同。

## 连拍提速改为开机默认关

开着连拍提速时，「连拍时查看全部」不能在连拍中显示取景。从这一版起，连拍提速每次开机都是关闭的；需要时在设定菜单「连拍提速」里打开，只在这次开机内有效。

## 电脑读取照片加速（未验证）

用 USB 连接电脑浏览相机里的照片时，加快照片列表的读取（Z30 `mtp-fast` 做法移植到 Z 5：每张照片的属性查询只读一次文件记录）。卡上有模块时自动生效，没有菜单项。

## 原理（简述）

- JPEG 颗粒：固件 JPEG 编码入口 `0x1009F33A` 的闸门（模块开启第 5 位时调用），在编码前改写亮度平面。颗粒场为开机生成的 256×256 小团颗粒，按亮度查表决定强度，每个 32 位字用 `USAD8`、乘法和 `QADD8` 处理 4 个像素，两字交错以减少等待。
- NEF 内的 Lightroom 设置：固件生成 NEF XMP 中 `crd:`（camera-raw-defaults）区块的函数 `0x101BCDF4` 收尾处 `0x101BCFA6` 的闸门（模块开启第 6 位时调用），由模块用固件自己的元素函数追加 `crd:GrainAmount`、`crd:GrainSize`、`crd:GrainFrequency`。设置取自拍摄那一刻的菜单。
- 两个闸门、MTP 加速的源码在 `src/firmware_hooks/z5_grain_fw.py`、`z5_crd_fw.py`、`z5_mtp_fw.py`；卡上模块的相关代码在 `src/card_module/jpeg_*.inc`、`a44_*.inc`、`a48_crd.inc`。没有模块或对应位未开启时，入口按原厂运行。
- 卡模块构建参数：`Z5_EXTRA=-DBULB_MENU -DJPEG_LOG -DBURST_EXTRA_BITS=0x60u -DJPEG_A42 -DJPEG_A43=1 -DJPEG_A44 -DJPEG_A45 -DSETUP_SAVE_REOPEN -DLIGHTROOM_GRAIN -DA48_CRD -DJPEG_A50 -DBURST_BOOT_OFF -DA51_KERNEL2`。
