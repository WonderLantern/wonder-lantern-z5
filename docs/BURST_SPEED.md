# 连拍提速：说明与实现

## 用户说明

设定菜单“扩展功能”下面新增一行 **连拍提速**，进去有两个开关（默认都开）：

| 开关 | 作用 |
| --- | --- |
| 机械快门提速 | 机械 / 电子前帘高速连拍 |
| 电子快门提速 | 静音（电子快门）高速连拍 |

实测（作者相机，高速连拍，M 档 1/1000 秒）。整合版 2026-11-16 实机复测：机械通过；静音没有达到研究版的效果：

| | 原厂 | 提速后 |
| --- | --- | --- |
| 机械，亮处 | 约 233 ms / 张（4.3 张/秒） | 约 195 ms / 张（约 5.1 张/秒） |
| 机械，暗处 | 约 270 ms / 张 | 约 195 ms / 张 |
| 静音 | 约 400 ms / 张（2.5 张/秒） | 整合版约 360–390 ms / 张（全画幅），DX 镜头约 410 ms，**基本没有提速**；研究版曾到约 300 ms，原因排查中 |

**重要限制：**

- **只适合单次对焦（AF-S）。** 提速的做法是连拍中不再等取景恢复、不再重新测光，所以曝光和对焦都停在第一张。AF-C 下也会按 AF-S 的方式工作，**不适合追踪运动主体**。
- 曝光锁在第一张：建议 M 档 + 固定 ISO；自动曝光时连拍中光线变化不会跟随。
- **请手动关闭原厂“连拍时查看全部”**（自定义设定菜单）。打开时提速连拍后屏幕可能黑着，半按快门或按菜单可恢复。模块不会替你修改这个设置（见下方“问题记录”）。
- 两个开关都关闭时恢复原厂连拍行为；拔卡或删除 `Z5APP.BIN` 也一样。

## 实现

固件只增加 3 个很小的入口，全部只在卡上模块请求时生效；没有模块时与第 108 组固件完全相同。

| 位置 | 原指令 | 作用 | 开关 |
| --- | --- | --- | --- |
| `0x10192F96` | `push {r4-r6, lr}; movs r4, #0` | 连拍间隔表入口：机械高速改用 125 ms 档，静音改用 166 ms 档 | 状态块 P+0x18 = `0xB500_0000 \| 静音档 << 8 \| 机械档`，P+0x1C 为反码 |
| `0x10206E6C` | `bl 0x10208370` | 暗光下也立即放行下一张（原厂暗光每张先回取景测光，约多 70 ms） | P+0x14 = `0xBF5A1C00 \| 位`，位 0 |
| `0x1020857A` | `movs r0, #0; bl 0x1020355A` | 每张拍完不再请求“回到取景”（静音提速的主要来源） | 同上，位 1 |

卡上模块（`src/card_module/burst_speed.inc`、`burst_speed_install.inc`）：

- 每 50 ms 一次的后台任务：按当前模式（静音字节 `0xC239F67A` = 2）决定是否生效；
- 把 5 个“等取景恢复”的拍摄占用号 0x56、0x3c、0x3d、0x59、0x3f 移出阻塞名单（`0xC18A89E0`，用固件自己的 `0x10062860` 移出，关闭时用 `0x100628A6` 加回），下一张不再等取景重新跑起来；
- 写上面的间隔字和开关字；
- 当前 fork L39 将机械关闭／电子关闭保存在 `MENU.DAT` 第 3 个字的 bit20／bit21（D8 标签）；第 4 个字保存自定义 DISP 总开关和两端页号。兼容读取旧 8 字节及 D215／D216／D7 的 12 字节格式，迁移后保存为 16 字节。旧 fork 原版水平仪与连拍位曾有冲突，迁移后请检查连拍开关。

研究过程（入口、占用表、暗光测光路径、取景命令顺序）见开发仓库 `research/burst/README.md` 的 L35–L52 记录。机械目前的下限来自传感器节拍对齐（每张两次），软件层面已基本到底；静音剩余最大的一段是两次 0x11 命令之间约 85 ms 的读出模式切换，仍在研究。

## 问题记录

- **2026-11-16，整合版实机复测**（模块 `afed83a9`，固件 `bf821031`）：开机正常；机械连拍全画幅 24-70 和 DX 12-28 都约 195 ms / 张。静音全画幅约 360–390 ms、DX 约 410 ms，记录显示模块已移出占用、开关字和间隔字都已写入，但没有达到研究版（L50/L51）的 300 ms，原因待查（怀疑与“连拍时查看全部”有关）。另有一次开机后第一组机械连拍为约 270 ms（原厂暗处速度），原因未查。

- **2026-11-16，测试记录写满后不能再保存**：发布版模块仍是旧的“写满即停”逻辑。改为循环覆盖：先用空文件，20 个都写满后覆盖最旧的一个（记录头偏移 0xBC 存序号，旧记录按 0 计，最先被覆盖）。模块 `afed83a9`。

- **2026-11-16，扩展功能菜单变成英文**：模块用设置 `0x1400` 判断语言，它其实是画质（JPG 时读到 3，被当成英文）。在找到真正的语言设置前，模块自己的菜单固定显示简体中文。测试记录在偏移 0xDA0 增加了连拍提速状态（开关、占用、任务、开关字），用于排查“提速失效”。

- **2026-11-16，第一版发布（模块 `04bb0f3c`）开机即死机、快门锁定**（拔电池和卡后恢复）。原因：模块的后台任务在开机过程中写入相机设置 `0x112C`（连拍时查看全部），开机流程卡住，快门停在关闭状态。模拟器复现：去掉这一写入后正常开机，去掉占用移出或开关字都不能消除；改为在菜单回调里写入，模拟器在打开“连拍提速”页时同样卡住。修正版（模块 `72bda745`）完全不再修改这个设置，固件不变（`bf821031`）。
